## AdSense and Google policy notes
- There is no AdSense code or analytics tag in this package.
- Do not put AdSense ads inside the editor UI or near photo upload, effect, navigation or download controls. Avoid non-content, loading, error and empty screens.
- Keep original, useful information visible and make the editor genuinely usable. Do not add misleading claims, fake reviews, keyword stuffing or doorway pages.
- If ads, analytics, cookies or third-party scripts are added, update the privacy notice and implement any consent requirements applicable to the visitors' locations.
- Technical setup does not guarantee AdSense approval or search ranking.
